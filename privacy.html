Privacy Policy — Maple Backup

Last updated: 2026-09-11

Maple Backup is a browser extension that automatically creates local, point-in-time backups of your bookmarks. This page explains what data the extension accesses, where it goes, and what it does not do.

What this extension accesses

Maple Backup uses your browser's Bookmarks API to read your bookmarks — titles, URLs, and folder structure — so it can create scheduled backups and let you view or export past versions.

Where your data is stored

All backups and settings are stored locally on your device, using your browser's built-in storage. Nothing is uploaded anywhere by default.

Your preferences (backup frequency, display language) are stored locally on your device and are not synced by Maple Backup.

What we do not do

This extension has no server of its own. It does not transmit your bookmarks, backups, or any other data to the developer. There is no analytics, tracking, or advertising code of any kind. The only exception is Cloud Backup, described below, and only for whichever provider(s) you choose to turn on.

Cloud Backup — optional

Maple Backup can optionally save copies of your local backups to a cloud storage provider of your choice: Google Drive, Microsoft OneDrive, Dropbox, Nutstore (坚果云), or Koofr. Each provider is off by default and only starts after you explicitly click "Connect" for that specific provider in Preferences — connecting one never turns on any of the others.

When a provider is connected, each backup (scheduled or manual) is also uploaded to a folder named "Maple Backup" in that provider's storage, in the same bookmarks file format as the Download button produces. If no provider is connected, nothing is ever uploaded.

Google Drive, OneDrive, and Dropbox are connected via that provider's own sign-in screen (OAuth) — Maple Backup never sees or stores your account password for these. Nutstore and Koofr don't offer this kind of sign-in, so instead you generate a separate "app password" in your own Nutstore/Koofr account settings and enter it directly into Maple Backup; this app password is stored locally on your device (see "Where your data is stored" above) and used only to authenticate uploads to your own Nutstore/Koofr account. It is never sent anywhere except directly to that provider's own servers.

Every provider uses the narrowest access mechanism it offers: Google's drive.file scope, Microsoft's Files.ReadWrite.AppFolder scope, and Dropbox's dedicated "App Folder" access type all restrict Maple Backup to only the files and folders it creates itself — it cannot browse, read, or modify anything else already in your account. Nutstore and Koofr are accessed over WebDAV, writing only inside the one "Maple Backup" folder created for this purpose.

Clicking "Disconnect" for a provider stops future uploads to it and, for Google Drive/OneDrive/Dropbox, revokes this extension's access to that account (for Nutstore/Koofr, it forgets the stored app password on this device — you can also revoke the app password itself from your Nutstore/Koofr account settings at any time). Backups already uploaded are not deleted automatically — you can remove them yourself from that provider's own storage at any time.

Maple Backup never downloads or restores your backup contents from any cloud provider. Every connection is a one-way backup destination — if you ever need a file back from one, you retrieve it yourself directly from that provider's own website.

Downloads

When you click Download on a backup, a bookmarks file is saved to your own device's Downloads folder, only when you explicitly request it. That file stays on your device and is never sent anywhere by the extension.

Permissions this extension requests

PermissionWhy it's needed
bookmarksRead your bookmarks to create backups.
storageStore backup history and your preferences locally.
alarmsRun the scheduled daily (or every N days) backup.
unlimitedStorageAllow backup history to grow beyond the browser's default storage limit.
identitySign you in to your own account, only if you choose to connect Google Drive, OneDrive, or Dropbox. Not used for anything else.
