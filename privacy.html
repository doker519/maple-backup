Privacy Policy — Maple Backup

Last updated: 2026-10-28

Maple Backup is a browser extension that automatically creates local, point-in-time backups of your bookmarks. This page explains what data the extension accesses, where it goes, and what it does not do.

What this extension accesses

Maple Backup uses your browser's Bookmarks API to read your bookmarks — titles, URLs, and folder structure — so it can create scheduled backups and let you view or export past versions.

Where your data is stored

All backups and settings are stored locally on your device, using your browser's built-in storage. Nothing is uploaded anywhere by default.

Your preferences (backup frequency, display language) are stored locally on your device and are not synced by Maple Backup.

What we do not do

This extension has no server of its own. It does not transmit your bookmarks, backups, or any other data to the developer. There is no analytics, tracking, or advertising code of any kind. The only exception is Cloud Backup, described below, and only for whichever provider(s) you choose to turn on.

Cloud Backup — optional

Maple Backup can optionally save copies of your local backups to Google Drive, Dropbox, pCloud, Nutstore (坚果云), or Koofr. The Chrome Web Store build offers Google Drive, Dropbox, and pCloud; a copy loaded directly from source offers Nutstore and Koofr. Google Drive backup requires Google Chrome; Dropbox and pCloud backup work in Chrome, Edge, and other compatible browsers. Each provider is off by default and only starts after you explicitly click "Connect" for that specific provider in the Cloud Backup tab — connecting one never turns on any of the others.

When a provider is connected, Maple Backup attempts to upload copies of new local backups as HTML bookmark files. Uploads are normally limited to once per hour per provider; a scheduled backup gets a follow-up check after 30 minutes to retry failed uploads once. Network problems or account authorization issues can prevent uploads. Files are saved in the provider's Maple Backup folder; in pCloud, this is the app-specific folder under Applications. If no provider is connected, nothing is uploaded.

Google Drive, Dropbox, and pCloud are connected via the provider's own sign-in screen (OAuth) — Maple Backup never sees or stores your account password for these. Account identifiers, folder references, and any OAuth tokens retained by the extension are stored locally on your device. Nutstore and Koofr connections use a separate "app password" that you generate in your own account settings and enter into Maple Backup; this app password is stored locally and used only to authenticate requests directly to that provider's servers.

Google Drive uses the drive.file scope, Dropbox uses dedicated App Folder access, and the pCloud application is configured for access to its specific app folder. These OAuth connections do not grant access to unrelated files elsewhere in your cloud storage. Nutstore and Koofr are accessed over WebDAV: Maple Backup writes backups only inside its Maple Backup folder, but the app password itself may permit broader account access. The extension may read account or folder metadata to validate a connection and locate the backup destination.

Clicking "Disconnect" stops future uploads to that provider and clears its locally retained credentials. OAuth connections also attempt to invalidate the relevant token with the provider; remote invalidation can fail, for example while offline. You can remove app access in the provider's account settings. For Nutstore and Koofr, disconnecting forgets the stored app password on this device; you can also revoke that app password in the provider's settings. Backups already uploaded are not deleted automatically — you can remove them yourself from that provider's storage.

Maple Backup never downloads or restores your backup contents from any cloud provider. Every connection is a one-way backup destination — if you ever need a file back from one, you retrieve it yourself directly from that provider's own website.

Downloads

When you click Download on a backup, a bookmarks file is saved to your own device's Downloads folder, only when you explicitly request it. That file stays on your device and is never sent anywhere by the extension.

Permissions this extension requests

PermissionWhy it's needed
bookmarksRead your bookmarks to create backups.
storageStore backup history and your preferences locally.
alarmsRun the scheduled daily (or every N days) backup.
unlimitedStorageAllow backup history to grow beyond the browser's default storage limit.
identitySign you in to your own account, only if you choose to connect Google Drive, Dropbox, or pCloud. Not used for anything else.

Google API network access is declared at installation. Network access for Dropbox, pCloud, Nutstore, and Koofr is optional and requested when you connect that provider, if permission has not already been granted. OAuth sign-in also opens the provider's own authorization page.
